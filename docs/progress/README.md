# Progress archive

Visual artefacts that have been superseded, kept in running order so this folder shows how the demo evolved. Nothing here is current; the live versions are in `docs/design/` and `docs/screenshots/`.

## Rule

- Each entry is a folder `NN-<slug>/`, numbered in the order it was archived (`01-`, `02-`, ...), never renumbered.
- When a build ticket ships, it moves its wireframe folder from `docs/design/<ticket>/` here.
- Before overwriting screenshots in `docs/screenshots/`, copy the current set here first.
- Add a line to the list below for each entry: what it shows and which ticket archived it.

## Entries

- `01-shop-scene-wireframe/` - the approved grey-box wireframe for the shop scene, archived when `shop-scene` shipped.
- `02-shop-scene-screenshots/` - the title and shop-scene screenshots as `shop-scene` shipped them, archived when `two-run-results` refreshed the set.
- `03-two-run-results-wireframe/` - the approved grey-box wireframe for the pitch flow and comparison, archived when `two-run-results` shipped.
